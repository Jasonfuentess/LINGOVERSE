# LV-006A · First English Adventure — Lost in London

**Alcance:** primera aventura inglesa A1, original, local, reutilizando Learning Engine, Variety Engine, progreso v1, proyección de conversación, TTS existente y Web Speech API de LV-005B-02. Sin nuevas APIs, dependencias, diario, pasaporte ni cambios de Git.

## Entregables

- `src/content/london.ts`: lección `en-a1-london-lost` / versión 1; nueve objetivos obligatorios por ruta, dos historias editoriales y decisiones que cambian personajes, indicaciones y desenlace.
- Rutas a través de Explorar e Inicio, reanudación y reinicio independientes de francés.
- Adaptación mínima del tipo de idioma a `en | fr`, presentación genérica de conversación, control TTS `en-GB`, STT `en-GB` con transcripción editable y fallback al teclado. Sin puntuación de pronunciación.
- Escena londinense original dibujada con primitivas React Native, con retratos tipográficos locales para personajes nuevos. París y Roast conservan sus recursos.
- Nuevas pruebas de contenido, ramas, alternativas, recuperación, persistencia multi-idioma, elección oral exacta, ausencia de revelación de diálogos futuros y permisos/fallback vía controlador simulado.
- Estado y entrega a Codex actualizados con resultados reales y QA pendiente.

## Criterios de aceptación

1. Ambas variantes ofrecen nueve objetivos educativos ordenados y dos rutas auténticas.
2. Las elecciones válidas se reflejan en nodos, personajes, escena, réplica y final.
3. Reanudar no cambia la variante ni la ruta; reiniciar no borra el progreso francés.
4. Cada intervención escrita tiene varias formulaciones aceptadas y cada selección varias respuestas válidas; fuera de estas equivalencias editoriales no se afirma comprensión semántica ilimitada.
5. Mostrar únicamente el turno activo y el historial recorrido, nunca futuros mensajes de otros nodos.
6. Audio del personaje en inglés británico solicitado a voces disponibles; captura web inglesa opcional, con indicación de privacidad, revisión de texto y fallback escrito.
7. `npm test`, `npm run typecheck:core`, `npm run typecheck`, `npm run lint`, `npm run export:web` en verde, con navegador/QA físico reportado de forma separada.

## Fuera de alcance

STT/TTS nativo confirmado en Android/iOS, análisis fonético/pronunciación, generación por IA, sincronización en servidor, cambios a contenido francés versionado, nuevas bromas, Diario y Pasaporte.

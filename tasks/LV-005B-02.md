# LV-005B-02 — Entrada oral mediante micrófono (web, primera iteración)

Fecha de implementación sobre el ZIP de continuidad: 2026-10-30 (fecha del proyecto); validación automatizada ejecutada en entorno Linux aislado.

## Objetivo y alcance

Permitir que una persona que realiza «Un café en París» oiga al personaje con LV-005B-01 y, **cuando el navegador lo soporte**, grabe una intervención de reconocimiento de voz FR (`fr-FR`) mediante acción explícita, revise/edite la transcripción y la utilice para responder al Learning Engine existente. La escritura y las opciones siempre siguen disponibles. No implementar calificación fonética ni afirmar que una transcripción demuestra buena pronunciación.

## Decisiones

- **Web primero**: `SpeechRecognition` / `webkitSpeechRecognition` nativos del navegador mediante adaptador. No se incorporan librerías, claves, servicios contratados ni permisos nativos; `expo-speech-recognition@^57` se estudia como siguiente fase, pero no se instala sin builds y QA real en Android/iOS.
- **Privacidad explícita**: leyenda en cada control antes de capturar voz. El navegador puede transmitir audio a un servicio propio/remoto; no se promete operación offline ni retención cero por parte del proveedor del navegador. LingoVerse no guarda audio: solo la respuesta aceptada y registrada por el mecanismo de progreso ya existente cuando se pulsa «Comprobar respuesta».
- **Consentimiento operativo**: no se llama a `start` hasta pulsar «Hablar en francés»; permisos se administran en el navegador. `document.visibilitychange`, `pagehide`, AppState y desmontaje cancelan reconocimiento. La síntesis se detiene antes de iniciar micrófono; una reproducción nueva cancela dictado.
- **No evaluación duplicada**: el reconocimiento entrega texto libre. Para ejercicios escritos se copia al borrador editable. Para decisiones de opción se exige coincidencia única con una opción visible usando el normalizador existente; la ambigüedad se resuelve editando o seleccionando manualmente. El estudiante siempre pulsa «Comprobar respuesta».
- **Contrato testeable**: controlador sin React con sesiones y epochs contra callbacks obsoletos, errores de permisos y cancelación; adaptación web aislada y adaptador nativo explícitamente deshabilitado.
